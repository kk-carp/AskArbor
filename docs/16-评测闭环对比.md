- 当前配置：默认 `RETRIEVE_USE_HYBRID=true` + `RETRIEVE_USE_RERANK=true`（`BAAI/bge-reranker-v2-m3`）

## 结论

在 55 条样本上，**质量指标与关 rerank 持平**：Recall@k=100.00%，正确拒答率=100.00%，隔离通过率=100.00%；估算单次成本 ¥0.001028（32/55 调模型）。

打开默认重排后，**延迟显著变差**：平均 20138.5 ms（P95 35575.8），相对关 rerank 的 1540.4 / 3142.4 ms。这不能当成「rerank 让检索更好」——样例语料上两边已经都是满分。

## 本轮改动

1. 在已加载 `bge-reranker-v2-m3` 的本机 API 上重跑同一 55 集（不再关 rerank）。
