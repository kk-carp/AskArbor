# 项目结构映射（旧路径 -> 新路径）

本映射用于把当前实现对齐到 `routes / services / domain / infra` 四层结构，保持行为不变、便于后续 V1/V2 迭代。Python 包目录现为 `backend/`（原 `app/`），Vue 工程现为 `frontend/`（原 `web/`）。

## 应用层映射

| 旧路径 | 新路径 | 说明 |
| --- | --- | --- |
| `backend/auth.py` | `backend/services/auth_service.py` | 登录、会话、用户加载；旧文件保留兼容导出 |
| `backend/ingest_service.py` | `backend/services/ingest_service.py` | 入库编排服务；旧文件保留兼容导出 |
| `backend/qa_service.py` | `backend/services/qa_service.py` | 问答编排服务；旧文件保留兼容导出 |
| `backend/membership.py` | `backend/domain/membership.py` | 成员关系与 `allowed_spaces` 规则 |
| `backend/roles.py` | 已删除；规则在 `backend/domain/membership.py` | 问答只读 `space_members`，不再按请求 role 映射 |
| `backend/chunker.py` | `backend/infra/chunker.py` | 切片能力 |
| `backend/parsers.py` | `backend/infra/parsers.py` | 文档解析能力 |
| `backend/storage.py` | `backend/infra/storage.py` | 文件落盘能力 |
| `backend/embed.py` | `backend/infra/embed.py` | 向量模型加载与编码能力 |
| `backend/retrieve.py` | `backend/infra/retrieve.py` | pgvector 隔离检索能力 |
| `backend/generate.py` | `backend/infra/generate.py` | DeepSeek 生成能力 |
| `backend/seed.py` | `backend/seed/demo_users.py` | 演示账号种子 |
| `backend/infra/open_resource_search.py`、`open_resource_search_init.py` | `backend/infra/open_resource/` | 拆为 `policy`（名单与过滤）/ `sources`（工具契约、注册表、解析、出网）/ `search`（编排）/ `bootstrap`（启动注册）；包 `__init__` 保留原有导出名 |
| （V1 新增） | `backend/services/ticket_service.py`、`backend/services/topic_owner_service.py` | 学员工单与内部负责人 |

## 路由依赖调整

- `backend/routes/ask.py`：改为依赖 `backend/services/auth_service.py` 提供登录态上下文，并调用 `backend/services/qa_service.py`。
- `backend/routes/auth.py`：改为依赖 `backend/services/auth_service.py`，避免路由内重复登录态解析逻辑。
- `backend/routes/documents.py`：改为依赖 `backend/services/ingest_service.py`。

## 兼容策略

- 保留原顶层模块（如 `backend/qa_service.py`）作为兼容导出，降低一次性迁移风险。
- 新代码优先从 `services/domain/infra/seed` 目录导入；旧导入路径仅用于过渡。

## `allowed_spaces` 统一入口与 `roles` 退场路径

- 当前唯一授权查询入口：`backend/domain/membership.py#get_allowed_spaces_for_user`。
- 路由统一通过 `backend/services/auth_service.py#load_auth_context` 获取登录用户与 `allowed_spaces`，避免在多个路由重复拼授权逻辑。
- `backend/domain/roles_compat.py` 与 `tests/unit/test_roles.py` 已删除；角色映射测试并入 `tests/unit/test_membership.py`。
