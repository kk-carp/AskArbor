## 1. 背景与目标



### 1.1 结论

V2-A 目标是在 **不重写 RAG 主链路** 的前提下，给学员侧接上「命中之后 / 未命中之后」的学伴能力：能问课程代码、能推荐课内资料与开源/免费课外阅读、能把截图送进既有问答。作业智能批改**暂不实现**。

智能助手（入职推荐、公司 Skill）留在 V2-B，见 `docs/V2-B需求分析.md`。

### 1.2 相对 V1 的增量


| 能力   | V1                              | V2-A                                  |
| ---- | ------------------------------- | ------------------------------------- |
| 知识源  | 手动上传 MD/PDF/docx                | 增加课程代码/课件；切片带来源路径（及符号名）               |
| 问答   | `/ask` 文本提问                     | 仍走同一检索；问代码必须带来源路径或文档标题                |
| 未命中  | 学员建工单                           | 不变；**OCR 失败不得建单，也不得伪装成** `hit=false`  |
| 批改   | 无                               | **暂不实现**                              |
| 学习路径 | 无                               | 按提问历史识别薄弱点；推荐课程空间已有资料，并搜索开源/免费课外阅读与论文 |
| 多模态  | 无                               | 截图/公式 OCR 后进入 `/ask`                  |
| 部署   | Compose：API + Postgres          | 不变                                    |
| 界面   | 产品入口 Vue 3（`docs/产品化前端需求分析.md`） | 学伴页随 A1–A5 接口接入同一 Vue                 |




### 1.3 硬约束（继承 MVP/V1，V2-A 不得破坏）

1. 单体 FastAPI + PostgreSQL/pgvector；不为学伴另起一套检索服务或向量库。
2. 空间过滤必须在检索 SQL 的 `WHERE` 中；插件禁止全库检索后再用 Python 过滤。
3. 客户端不得决定 `space_ids`；工具入参同样不得带可检索空间。
4. 未命中或低于阈值时不调用 DeepSeek；`/ask` 来源只来自召回记录（含代码切片的 path）。学习路径课内条目同样只来自召回；课外条目只来自搜索函数，不把模型输出的 URL 当来源。
5. 系统故障（502/503）、知识库未命中（200 + `hit=false`）、**工具失败** 三种语义必须区分。
6. 对话不得自动写入知识库。作业批改恢复前不建参考答案表。
7. 不为 V2 预建空的 `agents/` 包；有第一个学伴工具再加文件。
8. 学伴工具的知识上下文默认只使用 `student` 空间，即使教学岗 `allowed_spaces` 含 `company`（见 4.2）。

## 2. 范围与非目标



### 2.1 V2-A 范围内

对应任务拆分 V2-A1～A5。界面跟现有 Vue 产品入口，不单独立项 A6。

- **V2-A1 课程代码/课件入库：** 教学岗上传 zip/目录；按文件切片写入 `student`；切片带 path + language。问答来源含 path 或文档标题。内部仓不得进入 `student`。第一期不做 tree-sitter 符号、不做 Git clone。
- **V2-A2：** **不做。** 代码调试助手与隔离执行沙箱已从学伴范围删除；不提供 `POST /debug`，Compose 不增加沙箱容器。
- **V2-A3 作业智能批改：** **暂不实现。** 需求见基线 §8.1.2；本阶段不建 `assignments` / `submissions`，不提供批改接口与页面。
- **V2-A4 学习路径：** 根据该学员近期提问历史识别薄弱点。推荐分两类：**课内**（`student` 已入库资料，每条必须能对上 `document_id` 或 `path`）与 **课外**（服务端搜索开源、免费阅读资料与论文）。尽量不推荐收费课、训练营，以及对标本公司产品的课程。课外链接必须来自搜索函数结果，禁止模型编造 URL。
- **V2-A5 OCR：** 代码截图 / 公式图 → 识别文本 → 既有 `/ask`；OCR 失败 ≠ 知识库未命中。

学伴相关按钮与结果展示：产品入口见 `docs/产品化前端需求分析.md`；V2-A 第一期不阻塞该前端，学伴页在对应 API 就绪后接入同一 Vue。

### 2.2 V2-A 明确不做

- V2-B 全部：入职推荐、公司 Skill（文章生成、arXiv 等）。见 `docs/V2-B需求分析.md`。
- 把学伴做成第二套 FastAPI / 第二套 pgvector。
- 在学伴插件任务内重做一套前端框架（产品 Vue 由 `docs/产品化前端需求分析.md` 单独立项，与 A1–A5 并行）。
- 对话自动入库、无人确认写知识库。
- 作业智能批改（本阶段暂不实现；恢复时单独立项）。
- 代写作业、输出 `company` 空间代码或路径给学员。
- 代码调试助手、隔离执行沙箱、学员粘贴代码在服务端运行。
- 完整在线 IDE、全功能 Wiki、考试系统、入职带练。
- Redis / Celery / 对象存储 / 混合检索 / rerank（除非评测证明当前链路不够）。
- LangChain / LlamaIndex 作为内核。



### 2.3 已拍板（本专项）

1. **课程代码进库：** 教学岗上传 zip/目录，复用现有上传鉴权；空间强制 `student`。不在 A1 做 Git clone。
2. **来源粒度：** 第一期切片必须带仓库相对路径 + language；不要求 tree-sitter 符号名（函数/类）。问「某段代码含义」带来源 path 或文档标题即可。
3. **学伴界面：** 产品主入口为 Vue 3（见产品化前端需求）；A1–A5 仍可用 API 验收。本专项不包含 Gradio / SSE。
4. **学习路径信号：** 第一期只用 V1 会话近期提问，不建测验表、不建 `knowledge_points` / `learner_signals`。
5. **学习路径双列表：** `GET /learning-path` 同时返回 `course`（课内召回）与 `external`（课外搜索）。无 `hit` 字段。课内空、课外空、搜索失败三者语义分开，均不得写成 `hit=false`，不得建学员工单。
6. **课外必须走搜索函数：** 服务端按薄弱点关键词调用搜索（论文优先 arXiv 官方接口；通用网页须过主机白名单）。**禁止**把 DeepSeek 输出的 URL 当来源。服务端不跟用户/模型给的任意 URL 去抓页（防 SSRF）。搜索结果不入库。
7. **课外白名单（第一期，展示用链接的 host 必须命中）：** `arxiv.org`、`export.arxiv.org`、`github.com`、`huggingface.co`、`paperswithcode.com`、`wikipedia.org`、`zh.wikipedia.org`、`en.wikipedia.org`、`docs.python.org`、`pytorch.org`、`numpy.org`、`scikit-learn.org`、`cppreference.com`、`developer.mozilla.org`、`readthedocs.io`。不在名单内的搜索命中丢弃。
8. **课外黑名单：** 标题/摘要/URL 含「训练营」「付费课」「VIP 课」「会员课」「就业班」「名额」「报名立减」等则丢弃；主机命中 `udemy.com`、`coursera.org`、`edx.org`、`imooc.com`、`study.163.com`、`ke.qq.com`、`time.geekbang.org` 则丢弃。对标本公司产品的品牌名与域名放配置项 `LEARNING_PATH_BLOCK_KEYWORDS` / `LEARNING_PATH_BLOCK_HOSTS`（实现时写入 `config.py`，可空，但文档须列出填写位置）。
9. **搜索失败不毁掉课内：** 课内仍按召回返回；`external=[]` + `error_type=search_unavailable`（或超时 `search_timeout`）。



### 2.4 待确认（不阻塞 A1 开工，实现对应任务前需拍板）

1. **OCR 引擎：** 选型建议 PaddleOCR。
2. **zip 内忽略规则：** 建议忽略 `.git`、常见二进制、超大文件；具体名单实现 A1 时定。
3. **演示用课程代码包路径结构**（虚构课程即可）。
4. **通用网页搜索供应商：** 第一期默认用现有 `httpx` 调 **Tavily Search**（`https://api.tavily.com/search`，需 `TAVILY_API_KEY`），请求带展示白名单 `include_domains` 与收费课 `exclude_domains`；结果再过 `filter_search_hits`。不引入 Tavily SDK。无 key 时网页源记为 `search_unavailable`，论文源 arXiv 仍可用。论文检索走 arXiv（`export.arxiv.org`，超时 15 秒，与 V2-B5 主机一致）。
5. **对标本公司产品的具体品牌/域名：** 填进 `LEARNING_PATH_BLOCK_`*；未提供则第一期只拦第 2.3 条通用收费课/训练营主机与关键词。

## 3. 统一术语


| 术语     | 含义                                                  |
| ------ | --------------------------------------------------- |
| 学伴插件   | 只服务课程场景的工具；知识上下文默认 `student`                        |
| 来源路径   | 代码/课件切片上的仓库相对路径（如 `labs/sort.py`），由入库记录生成，不由模型编造    |
| 工具失败   | OCR 识别失败、课外搜索失败等；不是 `hit=false`，不建学员工单              |
| 课内推荐   | 学习路径中来自 `student` 召回的条目；须有真实 `document_id` 或 `path` |
| 课外推荐   | 学习路径中来自搜索函数的开源/免费阅读与论文；须有真实 URL 且 host 在白名单         |
| 参考答案   | 作业的标准答案；仅教学岗/助教可见全文                                 |
| 学伴身份使用 | 学员，或教学岗在调用学伴接口时被服务端裁剪为仅 `student`                   |


角色和空间标识仍为：`student`、`employee`、`teaching`（展示语义）、`company`。

## 4. 角色与权限



### 4.1 谁能用学伴能力


| 身份         | A1 入库 | A4 路径 | A5 OCR |
| ---------- | ----- | ----- | ------ |
| 学员         | 否     | 是     | 是      |
| 内部员工（非教学岗） | 否     | 否     | 否      |
| 教学岗        | 是     | 是     | 是      |


未登录一律 401。普通员工没有 `student` 成员关系，学伴接口返回 403，不得因为教学岗演示而让员工检到课程代码之外的内部仓。

### 4.2 学伴工具的空间裁剪（关键）

`/ask` 仍按 V1：`allowed_spaces` 来自 `space_members`（教学岗为两空间）。

学伴插件 **不得** 把教学岗的全部 `allowed_spaces` 送进路径或 OCR 知识上下文。学伴工具服务端固定使用 `student`（若用户对该空间无成员关系则 403）。

理由：教学岗若把 `company` 切片带进学伴 Prompt，会把内部实现泄露到学伴会话。

### 4.3 禁止事项

- 客户端传 `space_ids` / `role` 改变工具可见范围。
- 学员响应中出现 `company` 的标题、路径、片段、文档 ID。
- 用模型编造仓库路径、作业分数、或未出现在搜索结果中的外链。
- 把收费课、训练营、对标本公司产品的课程写进学习路径。
- 把课外搜索结果自动写入知识库。

## 5. 关键业务流程



### 5.1 课程代码入库（A1）

```text
教学岗登录
  → 上传课程代码 zip 或目录（空间由服务端定为 student）
  → 按文件解析；跳过无关文件（建议忽略 .git、二进制、超大文件，名单待确认）
  → 切片写入 chunks：content + embedding + space_id=student + path + language
  → 失败文件/条目 status=failed，不参与检索
```

问答仍走 `/ask`。命中代码切片时，`sources` 必须带 path（或文档标题）；path 来自数据库字段，模型不得改写来源列表。

### 5.2 调试（A2）

**不做。** 不提供粘贴报错执行、隔离沙箱或 `POST /debug`。学员问代码含义仍走 `/ask`（A1）。

### 5.3 作业批改（A3）

**暂不实现。** 不提供出题、提交、批改接口。恢复时按基线 §8.1.2，LLM 对比参考答案，不跑沙箱。

### 5.4 学习路径（A4）

```text
读取该学员近期会话问题（V1 messages 已有）
  → 空历史：200，weak_points=[]，course=[]，external=[]，说明提问不足，不编造薄弱点
  → 有历史：归纳薄弱点（可调 DeepSeek 只做主题归纳，不让它给链接）
  → 课内：仅 student + ready 检索 → course[]（document_id / title / path / space_id=student）
  → 课外：search_open_resources(薄弱点关键词)
        ├─ 论文：arXiv 官方接口
        ├─ 其它：网页搜索 → 只保留白名单 host
        └─ 丢弃：收费课/训练营主机、黑名单关键词、对标品牌
  → 合并返回；模型不得改写 course 来源，也不得往 external 塞未出现在搜索结果中的 URL
  → 课内无召回：course=[] + 说明；不因此调用未命中建单
  → 搜索失败：external=[] + search_unavailable / search_timeout；course 仍返回
```

第一期不建测验。课外结果不入库、不进入 `/ask` 向量库。教学岗调用时课内检索仍只有 `student`。

### 5.5 OCR（A5）

```text
学员上传图片
  → OCR
        ├─ 成功：文本作为问题或代码，进入既有 /ask
        └─ 失败：返回 ocr_failed，不建工单，不把失败说成知识库未命中
```

## 6. 数据与接口增量



### 6.1 表（相对 V1）


| 表或字段                                    | 用途           | V2-A 是否必须                |
| --------------------------------------- | ------------ | ------------------------ |
| `chunks.path` / `chunks.language`（或等价列） | 代码/课件来源路径与语言 | A1 必须                    |
| `assignments` / `submissions`           | 作业与提交        | A3 暂不建                   |
| `knowledge_points` / `learner_signals`  | 知识点与薄弱记录     | A4 第一期不建；用会话 + 检索 + 搜索函数 |
| OCR 无独立业务表也可                            | 失败靠日志与响应字段   | 可以                       |


有能力再建模，不预建空表。A1 未开始前不要加无调用方的 `code_symbols` 表；符号可先落在切片元数据。

### 6.2 接口增量（建议）

具体路径在任务拆分中可微调，语义不得偏离。


| 接口                                      | 说明                                  |
| --------------------------------------- | ----------------------------------- |
| 已有 `/ask` `/documents` `/login` 等       | 保持；学伴问答仍登录态                         |
| `POST /documents` 或 `POST /code-ingest` | 课程代码包入库；空间强制 `student`              |
| `GET /learning-path`                    | 薄弱点 + `course` + `external`；无 `hit` |
| `POST /ocr` 或 `/ask` 支持图片               | OCR 后进入问答                           |
| `GET /ask/stream`                       | 本专项不做 SSE                           |


`/ocr` 的成功响应不得把工具失败写成 `hit=false`。

`GET /learning-path` 建议体：

```json
{
  "weak_points": ["动态规划状态转移"],
  "error_type": null,
  "message": null,
  "course": [{"document_id": "...", "title": "...", "space_id": "student", "path": "labs/dp.md"}],
  "external": [{"title": "...", "url": "https://arxiv.org/abs/...", "host": "arxiv.org", "kind": "paper", "snippet": "..."}]
}
```

`kind` 第一期用 `paper` / `docs` / `oss`。`error_type` 仅 `search_unavailable`、`search_timeout` 或 null。无 `hit`。课外条目不得出现 `document_id`（未入库）。

## 7. 错误语义与审计


| 场景           | HTTP / 业务语义                              | 是否建学员工单     | 是否调 DeepSeek |
| ------------ | ---------------------------------------- | ----------- | ------------ |
| 未登录          | 401                                      | 否           | 否            |
| 员工调学伴接口      | 403                                      | 否           | 否            |
| 知识库未命中       | 200，`hit=false`                          | 是（学员，V1 规则） | 否            |
| DeepSeek 失败  | 502                                      | 否           | —            |
| DB / 向量模型未加载 | 503                                      | 否           | 否            |
| OCR 失败       | 200 或 4xx，`error_type=ocr_failed`        | 否           | 否            |
| 课内无可推荐       | 200，`course=[]` + 说明                     | 否           | 可不调或仅归纳薄弱点   |
| 课外搜索失败       | 200，`external=[]`，`search_unavailable` 等 | 否           | 否（失败路径）      |


审计在 V1 字段上增加：工具名、工具成功/失败、OCR 是否成功、引用 path 列表。仍不得把 `company` 路径写入学员侧日志展示。

## 8. 验收标准（学伴关卡）

与 `docs/需求分析.md` 第 11 节「V2 学伴」对齐：

1. 课程代码或讲义入库后，学员能问「某段代码含义」或算法原理，来源含文档标题或仓库路径；路径来自数据库。
2. 同一套内部代码 **不得** 出现在 `student` 检索中；学员问内部模块名，答案和来源中无该仓路径。
3. 学习路径：`course` 每条能在 `student` 对应到文档或 path；`external` 每条 URL 来自搜索结果且 host 在白名单；不出现收费课/训练营/编造链接。搜索失败时课内列表仍可用。
4. 截图能走通问答，或返回 OCR 失败；失败响应的 `hit` 不得为 false（除非 OCR 成功后检索确实未命中）。
5. 检索 SQL 仍含 `chunks.space_id = ANY(...)` 与 `documents.status = 'ready'`。
6. 作业批改本阶段不验收。

A6 本专项不做。命中判断与鉴权仍只在 FastAPI。

## 9. 现状差距（相对当前仓库）

对照时间点：V1-T1～T7 已落地；V2-A1 已落地（切片可带 path/language）。无 OCR。作业批改暂不实现。代码调试助手与沙箱不在范围。


| 任务                    | 状态        | 说明                                           |
| --------------------- | --------- | -------------------------------------------- |
| V2-A1 代码/课件路径入库       | **已完成**   | `POST /code-ingest`；`chunks.path`/`language` |
| V2-A2 代码调试助手          | **不做**    | 已从学伴范围删除；无 `POST /debug`、无沙箱容器               |
| V2-A3 作业批改            | **暂不实现**  | 不建 assignments；恢复时单独立项                       |
| V2-A4 学习路径            | **已完成**   | `GET /learning-path`；课内 student 召回 + 课外搜索白名单 |
| V2-A5 OCR             | **未开始**   | `/ask` 仅文本                                   |
| V2-A6 Gradio/SSE/独立前端 | **本专项不做** | 学伴页接入现有 Vue                                  |




### 9.1 风险

1. 教学岗两空间成员若原样传入路径/OCR 知识上下文，会泄露 `company`。
2. 检索阈值过低时，OCR 后的 `/ask` 仍会「假命中」，与 V1 工单问题同类。
3. 过早引入 Vue/Gradio 会把工期从插件挪到换皮；A1、A4、A5 不依赖新前端也能用 API 验收。
4. 学习路径若让模型直接输出外链，会编造付费课或对标产品；课外必须过搜索函数 + 白名单。
5. 课外搜索若接受客户端/模型任意 URL，会变成 SSRF。



### 9.2 建议落地顺序

```text
V2-A1 课程代码路径入库
    │
    ├─► V2-A5 OCR（可与 A1 并行，都接到 /ask）
    │
    ▼
V2-A4 学习路径（V1 会话 + student 检索 + 课外搜索函数）
```

V2-A3 作业批改本阶段不排期。学伴入口同步做进 Vue，不单独排 A6。
