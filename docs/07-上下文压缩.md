## 1. 背景与目标

### 1.1 改造前

```text
POST /ask
  → load_recent_history（最近 N 轮硬截断）
  → retrieve（当前问 + 可选追问拼句）
  → generate（system + history + 本轮依据）
```

配置项 `conversation_history_turns`（默认 3）只保留最近完整轮次（用户+助手）。更早对话直接丢弃，追问依赖早期事实时模型看不到。

### 1.2 要解决的问题

| 现象 | 原因 |
| --- | --- |
| 长会话后模型「忘了」前面约定 | 硬截断丢弃溢出轮次 |
| 若把全文历史都塞进 prompt | token 与费用上涨，且易冲淡本轮知识库依据 |

### 1.3 目标

1. 超出窗口的旧消息**滚动压入** `conversation.context_summary`。
2. 生成时注入：**摘要（system 段）+ 最近 N 轮原文**。
3. **检索不变**：仍只用当前问 + `followup` 拼句；摘要不进 `documents`/`chunks`。
4. 压缩失败时回退为纯截断（可保留旧摘要）；**不**把压缩失败抬成 502 / 伪装未命中。
5. 可用配置关闭压缩，行为回到仅最近 N 轮。

### 1.4 非目标

- 本仓 Skill 包、长任务 `agent_tasks`、MCP Client（见 [15-MCP-Client.md](./15-MCP-Client.md)）；跨会话 Memory 见 [14-跨会话Memory.md](./14-跨会话Memory.md)。
- 摘要自动入库或当作 KB `sources`。
- 前端展示摘要、Redis / Celery、LangChain。
- 按精确 tokenizer 计费的 token 预算（本版用消息条数窗口 + 摘要字符上限）。

## 2. 总体数据流

```text
POST /ask（已登录、有会话）
  → get_or_create_conversation
  → load_context_for_generate
       ├─ 正序加载全部 messages
       ├─ _maybe_roll_summary（必要时一次 complete_chat）
       └─ 返回 summary + 最近 keep 条原文
  → retrieve（仅 question / followup；不用 summary）
  → generate_*（system → 摘要 system → history → 本轮 user）
  → append_turn + commit
```

无会话（`user_id` 为空）的路径不走压缩，与改造前一致。

---

## 3. 数据模型

表 `conversations` 新增列（`create_all` + 启动时 `ALTER IF NOT EXISTS`）：

| 列 | 类型 | 含义 |
| --- | --- | --- |
| `context_summary` | `TEXT` 可空 | 滚动摘要正文 |
| `summary_message_count` | `INTEGER NOT NULL DEFAULT 0` | 按时间正序，已折进摘要的消息条数 |

删除会话时随行级联删除消息，无需单独清理摘要。

实现：[`backend/models.py`](../backend/models.py)、[`backend/db.py`](../backend/db.py) `_ensure_conversation_summary_columns`。

---

## 4. 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `conversation_history_turns` | `3` | 保留原文的完整轮数；`keep = turns * 2` 条消息 |
| `conversation_compress_enabled` | `true` | `false` 时只截断，不调用摘要模型 |
| `conversation_summary_max_chars` | `2000` | 写入前对摘要做空白归一与截断 |

见 [`backend/config.py`](../backend/config.py)、[`.env.example`](../.env.example)。

## 5. 压缩算法

入口：`load_context_for_generate(session, conversation_id)`  
实现：[`backend/services/conversation_service.py`](../backend/services/conversation_service.py)

### 5.1 步骤

1. 加载会话；正序取出全部 `messages`。
2. `keep = conversation_history_turns * 2`；`history` = 最近 `keep` 条（与原 `load_recent_history` 窗口一致）。
3. 若 `conversation_compress_enabled` 且 `total > keep` 且 `summary_message_count < total - keep`：
   - 溢出段 = `rows[summary_message_count : total - keep]`
   - 将「已有 `context_summary` + 溢出段」交给 `_summarize_overflow`（一次 `complete_chat`，短 system 提示）
   - 成功则写回 `context_summary`、`summary_message_count = total - keep`，并 `flush`（由问答事务提交）
4. 摘要调用异常：打审计日志，**不更新**计数；返回已有 summary（可空）+ 最近 N 轮。
5. 返回 `ContextForGenerate(history, summary)`。

再次进入且 `summary_message_count` 已覆盖当前溢出区间时，**不再**调模型。

### 5.2 摘要提示约定

- 只保留对后续追问有用的事实、偏好与未决问题。
- **不得**编造课程规定或公司制度。
- 输出纯文本；写入前按 `conversation_summary_max_chars` 截断。

### 5.3 与 `load_recent_history` 的关系

`load_recent_history` 仍保留（兼容/单测）。问答主路径改用 `load_context_for_generate`。

## 6. 生成注入

[`backend/infra/generate.py`](../backend/infra/generate.py)：

- `_append_history(..., conversation_summary=)`：在主 system 之后、多轮 history 之前插入一条 **system**，标明「更早对话摘要，不得覆盖本轮知识库依据 / 不得当作来源」。
- `generate_answer` / `generate_answer_stream` / `generate_general_assist` / `generate_general_assist_stream` 均透传该参数。

[`backend/services/qa_service.py`](../backend/services/qa_service.py) 同步与流式在取完 `ctx` 后：

- `history_tuples` → 生成与 `last_user_question`（追问）
- `conversation_summary` → 仅生成
- **不**传入 `_retrieve` / `expand_followup_query`

## 7. 失败与语义边界

| 情况 | 行为 |
| --- | --- |
| 压缩上游失败 | 日志；保留旧摘要与旧计数；仅最近 N 轮进 prompt；问答继续 |
| 知识库未命中 / 低于阈值 | 与改造前相同（拒答或学员实践参考等） |
| 生成 502/503 | 与改造前相同：rollback，不落本轮问答；与压缩失败区分 |
| 关闭压缩开关 | 等同硬截断；不调用摘要模型 |

## 8. 测试与验收

单测（节选）：

- `tests/unit/test_conversation_service.py`：超窗口滚动、二次加载不重复摘要、关闭压缩、压缩失败回退
- `tests/unit/test_generate.py`：摘要位于 history 之前
- 既有 `/ask` 单测改为 mock `load_context_for_generate`

手工验收：

1. 同会话连续超过 `conversation_history_turns` 轮后，库中 `context_summary` 非空且 `summary_message_count` 递增。
2. 命中路径 DeepSeek 请求含摘要 + 最近 N 轮原文。
3. `CONVERSATION_COMPRESS_ENABLED=false` 或 mock 摘要失败：行为退回截断，命中/拒答不变。

## 10. 一句话

**长会话用滚动摘要保住早期线索，最近 N 轮仍给原文；摘要只进生成、不进检索与知识库，失败就截断，不动 RAG 判据。**
