## 1. 结论

对着仓库就能讲：**26 提示词**（JSON schema + 失败重试）、**28 RAG**、**29 工作流约束**、**30 Agent**（进阶资料推荐）、**31 视觉（OCR）**、**27 / 47**（延迟与 token 报表 + 越权评测作业），以及已落地的 **SSE 流式输出**（`/ask/stream`、`/advanced-resources/plan/stream`）。

**不再纳入本项目：** Gradio / Streamlit 演示壳、LangChain 对照实验、LoRA 微调实验、语音转写进 `/ask`。旧文档若仍写「可选实验 / experiments/」，以本文为准作废。

已落地、不必再列为缺口：26、27、28、29、30、31（OCR）、41、47，以及 **`/ask/stream` SSE**。

可选加深（仍挂在本仓，不另起内核）：
