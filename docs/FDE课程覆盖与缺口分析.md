# FDE 全课程覆盖与缺口分析


| 项    | 内容                                                                         |
| ---- | -------------------------------------------------------------------------- |
| 文档性质 | 对照 FDE「01–55 课」与本仓库（统一知识助手）的**教学映射**；说明已体现、部分体现、缺口与是否应进产品                  |
| 项目定位 | AI 开发实践主项目：Python + FastAPI + Vue3 + Postgres/pgvector + RAG；**不是**全技术栈样例仓 |
| 原则   | 能挂在现有 RAG/学伴/助手链路上的优先补；换栈/机器人/低代码等用对照讲或 `experiments/`，不拆第二套内核             |


**读法：**


| 标记       | 含义                              |
| -------- | ------------------------------- |
| ✅ 已体现    | 主仓有可对着讲的代码或文档产物                 |
| 🟡 部分体现  | 有相关能力，但深度/广度不够上课「通关」            |
| ❌ 缺口     | 仓库几乎无对应；需补实验、对照演示或明确「课外对照」      |
| 🚫 不宜进本仓 | 技术栈/领域与本项目冲突或产品明确不做；上课用别仓/仿真/讲义 |

## 1. 总览结论

本项目是 FDE **AI 交付主线**的实践载体，强项集中在：

- **26–29、39（部分）、28 全链路**：提示词约束、DeepSeek API、RAG、拒答/分流工作流  
- **18 / 06 / 22 / 11 / 15 / 23**：FastAPI、SQL+pgvector、Docker Compose、Vue3、HTTP 客户端、Git 协作痕迹  
- **V2-A**：代码入库、进阶资料推荐、OCR（视觉进问答）

相对整份 01–55 课表，**大量工程课（Java/Go/PHP/Flutter/小程序等）与具身智能课本来就不该塞进本仓**；真正「AI 部分该有、仓库仍弱」的缺口主要是：

1. **Agent 白名单（第 30 课）** — 产品设计为「进阶资料推荐」（见 `docs/进阶资料推荐设计.md`，待实现）；自研编排，不用 LangGraph
2. **流式对话 / 快速原型壳（第 5 章意向、42）** — SSE、Gradio/Streamlit 未进主产品
3. **选型成本与评测闭环（27、36、47）** — 有 phase1 脚本，缺持续成本/安全评测课设
4. **LoRA / 语音 / 视频（32、31 后半）** — 应用隔离实验，未进检索内核（符合基线）
5. **LangChain / Dify 对照（40、43）** — 选型明确自研；需「对照实验」而非替换内核
6. **CI/CD、Nginx、Redis（20、21、25）** — Compose 有 DB，缺网关/缓存/流水线教学样例
7. **业务工作坊文档化（33–38）** — 需求/架构文档有，缺「驻场交付」课设作业模板

下面按课号逐项。

## 6. 「AI 开发部分」优先补齐清单（建议）

若目标是：**教授的 AI 相关内容尽量在本项目有落点**，按性价比排序：

### P0（上课马上痛、且符合产品边界）

1. **第 30 课 Agent**：落地「进阶资料推荐」（`/advanced-resources`，自研白名单）；可选实验目录对照，**禁止**为上课破坏 `/ask` 拒答逻辑
2. **第 25 课 CI**：GitHub Actions 跑 `pytest` + ruff
3. **第 27/36/47**：扩展 `scripts/run_phase1_eval.py`（延迟、近似 token、越权用例）+ 简短「评估与安全」作业说明
4. **第 26 课**：薄弱点/生成 JSON 校验失败重试的最小实现或对照实验



### P1（体验与部署课）

1. **SSE 流式** `/ask`（或实验级流式）对应第 5 章/18 课加深
2. `deploy/nginx.conf` **示例** + README 一节（21）
3. **Gradio 实验壳** 调同一 API（42），注明非产品入口
4. **语音 → 文本 →** `/ask` 实验脚本（31），不入库音频



### P2（对照与选修，不改内核）

1. LangChain 最小 RAG 对照目录（40）
2. Dify 搭建同场景说明文档（43）
3. Redis 缓存会话/进阶资料实验（20）
4. 前端部分 TS 化或 React 对照页（02/11）



### 明确维持「不进主仓」

- 03–05、08–09、13–14、16–17、19、48–55  
- 生产级 Skill 平台对接（另开产品专项）  
- LoRA 替换线上 Embedding/Chat
