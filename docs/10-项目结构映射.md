# 项目结构

> **补充参考**：当前目录与职责。权威索引见 [README.md](./README.md)。

Python 包在 `backend/`，Vue 在 `frontend/`。分层：`routes` / `services` / `domain` / `infra`。

## 后端

| 路径 | 职责 |
| --- | --- |
| `backend/services/auth_service.py` | 登录、会话、加载用户与 `allowed_spaces` |
| `backend/services/ingest_service.py` | 文档入库编排 |
| `backend/services/qa_service.py` | 问答编排 |
| `backend/services/ticket_service.py`、`topic_owner_service.py` | 学员工单、内部负责人 |
| `backend/services/memory_service.py` | 跨会话显式记忆 |
| `backend/services/agent_task_service.py` | 进阶资料长任务 |
| `backend/services/mcp_tooling.py` | MCP Client 组合根 |
| `backend/domain/membership.py` | `get_allowed_spaces_for_user`；问答只读 `space_members` |
| `backend/infra/embed.py` / `retrieve.py` / `rerank.py` / `generate.py` | 向量、隔离检索、重排、生成 |
| `backend/infra/mcp/` | MCP Client 原语 |
| `backend/infra/open_resource/` | 课外搜索：policy / sources / search / bootstrap |
| `backend/seed/demo_users.py` | 演示账号（仅 `APP_ENV=local`） |

新代码从 `services` / `domain` / `infra` / `seed` 导入。已无顶层 `backend/qa_service.py`、`backend/roles.py` 兼容层。

## 路由

- `routes/ask.py`：登录态 → `qa_service`；不接受 `role` / `space_ids`。
- `routes/auth.py`：`auth_service`。
- `routes/documents.py`：`ingest_service`。

## `allowed_spaces`

唯一授权查询：`backend/domain/membership.py#get_allowed_spaces_for_user`。路由经 `auth_service.load_auth_context` 取登录用户与空间列表。角色映射测试在 `tests/unit/test_membership.py`。
