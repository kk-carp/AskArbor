# V2-B 智能助手需求分析


| 项    | 内容                                                                              |
| ---- | ------------------------------------------------------------------------------- |
| 对应基线 | `docs/需求分析.md` 第 8.2、8.3、9–11 节；`docs/系统架构设计.md` 第 10.2 节；`docs/任务拆分.md` V2-B 表 |
| 对应选型 | `docs/技术选型.md` 第 9.2 节（本专项无新出网依赖）                                           |
| 前置   | V1 已完成                                                                         |
| 范围   | 岗位字段 + 入职类问句时检索 query 拼接岗位中文名（仍走既有 `/ask`）                                   |
| 不在范围 | 独立入职页、四类分桶清单、`GET /onboarding`、公司 Skill、完整 HR、另起检索内核                         |


**拍板：** 不另做「入职推荐产品功能」。普通 `/ask` 已能推荐相关文档；本阶段只做 **轻量增强**：问句像入职时，检索向量用的 query 拼上账号岗位中文名，提高岗位相关资料召回。作答与 `sources` 规则不变。

公司 Skill / SkillHub 对接本仓库不做。

---

## 1. 目标

员工在现有问答页问「入职要看什么」等时，若账号有 `position_key`，检索更偏向该岗位相关的 `company`（及教学岗其 `allowed_spaces` 内）已入库文档；来源仍来自召回，不编造。

不做独立页面、不做四类强制清单、不保证指南/仓/文档/任务都出现。

---

## 2. 范围内

- **V2-B2 岗位依据：** `users.position_key` 可空；seed；`GET /me` 返回。不拿客户端字段改检索范围。
- **V2-B1 检索增强：** 服务端判定入职类问句后，若存在岗位中文名，则 `encode_query(原问句 + " " + 岗位中文名)`；否则保持原问句。其余命中/未命中/生成/来源逻辑不变。

## 3. 明确不做

- 独立入职页 / `GET /onboarding` / 四类 path 分桶服务。
- 公司 Skill；无岗位时的特殊 `error_type` 产品流（无岗位则不加后缀，走普通检索即可）。
- 飞书同步（演进上本地库仍为检索真相源，另开需求）。

## 4. 已拍板细节

1. `employee_demo` / `teaching_demo` → `algo_engineer`；`student_demo` → null。
2. 岗位中文名映射第一期：`algo_engineer` → `算法工程师`（未知 key 则不拼接，避免噪声）。
3. 入职意图（保守，命中任一子串即可，可后续改配置）：  
   `入职`、`新人`、`报到`、`onboarding`、`入职指南`、`入职资料`、`先看什么`、`要看哪些资料`、`要看什么资料`。
4. 仅当意图命中 **且** 能解析出岗位中文名时才改检索 query；生成用的「用户问题」仍用原文。
5. 空间：仍用该次 `/ask` 的 `allowed_spaces`（不单独裁成仅 company）。学员本来无 company，问入职也捞不到内部文档。
6. Vue：不新增入职页；`/me` 可带 `position_key`；顶栏展示可选。

## 5. 流程

```text
/ask 收到问题
  → 若像入职问句且用户有已知 position_key 中文名
        → retrieval_query = question + " " + 岗位中文名
     否则 retrieval_query = question
  → encode_query(retrieval_query) → 既有 search_chunks(allowed_spaces)
  → 命中 / 未命中 / 生成 / sources 同 V1
```

## 6. 验收

1. `employee_demo` 有 `position_key=algo_engineer`；`/me` 可见。
2. 问「入职要看哪些资料」时，检索使用的 query 含「算法工程师」（单测断言即可）；回答来源仍为召回。
3. 无岗位或非入职问句：检索 query 不加岗位词。
4. 不出现独立入职页；无 Skill 路由要求。

## 7. 落地顺序

```text
V2-B2 岗位字段 → V2-B1 问句判定 + 检索 query 拼接
```
