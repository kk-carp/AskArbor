# 统一知识助手技术选型

> **补充参考**：依赖与引擎选型说明；**不是课表**。权威索引见 [README.md](./README.md)。架构见 [03-系统架构.md](./03-系统架构.md)。

| 项 | 结论 |
| --- | --- |
| 项目性质 | FDE 课程实践；学伴与智能助手共用一套内核 |
| 当前范围 | 隔离 RAG + 登录 Vue 产品 + 评测闭环；进阶资料 / OCR / CE 已挂在内核上 |
| 后端 | Python 3.11+、FastAPI、Uvicorn |
| 向量 / 重排 | 本地 `BAAI/bge-m3`（1024 维 dense）+ `BAAI/bge-reranker-v2-m3` |
| 大语言模型 | DeepSeek（OpenAI 兼容接口）；本机 `.env` 可指定模型名 |
| 数据库 | PostgreSQL 16 + pgvector，Docker 启动 |
| 文档格式 | Markdown / TXT、PDF、DOCX、PPTX；课程 zip |
| 前端 | Vue 3（`frontend/`，Element Plus）；FastAPI 可同源托管 `frontend/dist` |

设计原则：一条内核完成「文档入库 → 隔离检索 → 生成答案 → 展示来源」。场景能力挂在内核之后。代码执行沙箱不在产品范围。两场景不选两套技术栈。

---

## 1. 系统要完成什么

1. 教学岗将文档上传到 `student` 或 `company`。
2. 解析、切片，BGE-M3 入库；检索默认 hybrid + rerank。
3. 按登录用户的 `space_members` 限制检索空间。
4. 有可靠片段时调用 DeepSeek，返回文档来源。
5. 没有可靠片段时明确拒答，不编造答案或来源。

```text
文档上传 → 解析切片 → BGE-M3 → pgvector
  → 登录身份限制空间并检索（hybrid + rerank）
  → 命中：DeepSeek + 来源
  → 未命中：固定拒答（学员实践参考等既有例外除外）
```

### 身份与空间

空间由服务端计算，客户端不能指定 `space_ids`，也不能在 `/ask` 里传 `role`。

| 角色 | 可检索空间 |
| --- | --- |
| `student` | `student` |
| `employee` | `company` |
| `teaching` | `student`、`company` |

```sql
WHERE space_id = ANY(:allowed_spaces)
```

禁止先检索全部向量，再在 Python 中过滤。

## 2. 技术架构

```text
浏览器（Vue 3）
   │ HTTP + Session Cookie
   ▼
FastAPI
├── 登录 / 文档 / 问答 / 工单 / 进阶资料
├── 解析、切片、BGE-M3、reranker（进程内）
├── 空间过滤与 hybrid 检索
└── DeepSeek 客户端
   │
   ▼
PostgreSQL + pgvector（Docker）
```

不引入 Redis、Celery、Nginx、对象存储或独立 BFF。前端开发期 Vite 代理到 `:8000`，不是第二套后端。

## 3. 具体技术选型

### 3.1 FastAPI

接口少、Python AI 链路为主。不使用 Django、NestJS，不拆微服务。

主要接口：`POST /login`、`GET /me`、`POST /documents`、`POST /ask`、`POST /ask/stream`、`GET /health`。问答体只有 `question` 与可选 `conversation_id`。

### 3.2 BGE-M3 与 rerank

- 入库 / 问题向量：`BAAI/bge-m3`，`sentence-transformers`，进程内加载一次，1024 维 dense。
- 检索：jieba + PostgreSQL `tsvector` 与 dense 做 RRF，再 `BAAI/bge-reranker-v2-m3` 重排。详见 [05-混合检索.md](./05-混合检索.md)。
- 不用 BGE-M3 sparse / ColBERT。内存不够时可改 `RERANK_MODEL` 为 `BAAI/bge-reranker-base`，或关 `RETRIEVE_USE_RERANK`。

国内下载受阻：`HF_ENDPOINT=https://hf-mirror.com`。

### 3.3 DeepSeek

- SDK：官方 `openai` Python SDK；地址默认 `https://api.deepseek.com`。
- 只根据检索片段组织答案；来源由服务端从召回记录生成。
- 内网可把基址指到兼容服务，不在 API 进程再加载一套对话权重。

### 3.4 PostgreSQL + pgvector

- 镜像 `pgvector/pgvector:pg16`；`vector(1024)`；cosine `<=>`。
- 默认 `top_k=5`；门控默认 `retrieve_min_score=0.5`，开 rerank 时用 `rerank_min_score=0.5`。
- 当前数据量不建 HNSW / IVFFlat。

### 3.5 文档解析与切片

| 格式 | 处理 |
| --- | --- |
| Markdown / TXT | UTF-8 |
| PDF | `pypdf`（扫描件不在解析器做 OCR） |
| DOCX | `python-docx` |
| PPTX | `python-pptx`（文本框/表格/备注） |

切片按段装窗，约 800 字、重叠 100。截图走独立 OCR 后再进 `/ask`。

### 3.6 前端

Vue 3 + Vite + Element Plus。不传 `role` / `space_ids`，不在浏览器二次过滤来源。产品入口仅为 Vue，不做 Gradio / Streamlit。

---

## 4. 数据模型（要点）

知识库：`spaces`、`documents`（含 `offline` / `content_hash`）、`chunks`（向量 + `content_tsv`）。`chunks.space_id` 冗余以便 SQL 过滤。

产品表：`users`、`space_members`、会话与消息、`user_memories`、学员工单、`topic_owners`、`agent_tasks` 等。启动时 `create_all`，不用 Alembic。

---

## 5. 核心处理流程

### 5.1 入库

校验空间与文件 → 本地 `data/uploads/` → `processing` → 解析切片 → 向量 → `ready`。失败标 `failed`，不得检索。同步执行，不引入任务队列。

### 5.2 问答

1. 登录用户 → `allowed_spaces`。
2. 问题编码；hybrid 召回；默认 rerank。
3. 低于阈值或空结果：默认拒答，不调 DeepSeek。
4. 命中：DeepSeek + 服务端来源（含 `snippet`）。

不使用 LangChain / LlamaIndex。短链路便于验证隔离、拒答和来源真实性。

## 7. 配置

以仓库根目录 `.env.example` 为准。至少需要 `DATABASE_URL`、`CHAT_API_KEY`、`SECRET_KEY`。`RETRIEVE_MIN_SCORE` 默认与 rerank 门控为 0.5。密钥只在本地 `.env`，不得提交。

---

## 8. 验收口径

1. `student` 能答课程样例并带来源，问内部制度则拒答且来源无 `company`。
2. `employee` 能答内部样例；问课程截止日期则来源无 `student`。
3. `teaching` 能检索两个空间。
4. 知识库没有的内容 `hit=false`，且不调用 DeepSeek（实践参考等既有例外除外）。
5. 检索 SQL 能看到空间条件先于向量排序。
6. 课上 12 条与扩展评测见 [02-评估作业.md](./02-评估作业.md)。

## 9. 已落地、不必当缺口的选型

| 能力 | 选型 |
| --- | --- |
| 鉴权 | Session Cookie + `users` / `space_members` |
| 产品界面 | Vue 3；FastAPI 托管 `dist` |
| 部署 | Compose：API + Postgres |
| 转人工 | 学员工单；内部负责人表 |
| 流式 | `/ask/stream` SSE；命中判断在出字前完成 |
| OCR | Qwen-VL 优先，Paddle 可选兜底 |
| 进阶资料 | 白名单工具 + 课外搜索（arXiv / Tavily） |
| 入职增强 | 入职类问句检索 query 拼岗位中文名 |
| MCP | 本仓 Client，`off/shadow/merge`；**不做** Server |
| 观测 | `request_id`、教学岗进程内指标、评测报表 |

课外搜索：`httpx` 调 arXiv 与 Tavily；无 Tavily key 时记 `search_unavailable`。不引入 `tavily` SDK。
