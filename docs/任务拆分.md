| 项 | 内容 |
| --- | --- |
| 对应需求 | `docs/需求分析.md` 第 4 节（MVP）、第 7–8 节（V1/V2）；V1 专项 `docs/V1需求分析.md`；学伴专项 `docs/V2-A需求分析.md`；助手专项 `docs/V2-B需求分析.md`；产品入口 `docs/产品化前端需求分析.md` |

MVP 每个任务必须能单独验收：有明确交付、验证命令和通过标准。未通过验证不进入后续任务。目录骨架（T0）已完成。V1/V2 任务在 MVP 验收通过后再拆实现，不得提前引入登录、工单、沙箱等依赖。

## T0 目录骨架（已完成）

模块文件、Pydantic 契约、SQLAlchemy 表定义、`docker-compose.yml`、`.env.example` 已就位。本任务不再改范围。

验证：仓库根目录存在 `backend/`、`tests/`、`docker-compose.yml`，且无 `apps/`。

## T1 角色到空间映射

**目标：** 服务端根据模拟身份计算允许空间，客户端不能指定 `space_ids`。

**交付：** `backend/roles.py`、`tests/test_roles.py`

**验证：**

```text
pytest tests/test_roles.py
```

**通过标准：**

- `student` → `["student"]`
- `employee` → `["company"]`
- `teaching` → `["student", "company"]`
- 未知角色抛出明确参数错误，而不是返回空列表

---

## T2 文本切片

**目标：** 按约 800 字符切片、相邻重叠约 100 字符，丢弃空片段。

**交付：** `backend/chunker.py`、`tests/test_chunker.py`

**验证：**

```text
pytest tests/test_chunker.py
```

**通过标准：**

- 空文本或仅空白 → 空列表
- 短于窗口的文本 → 单个片段
- 长文本片段长度与重叠符合约定
- 不做标题感知或语义切片

---

## T3 文档解析

**目标：** 把 md/txt/pdf/docx 转成纯文本；空文本与扫描件失败。

**交付：** `backend/parsers.py`、`tests/test_parsers.py`、测试用小文件夹具

**验证：**

```text
pytest tests/test_parsers.py
```

**通过标准：**

- `.md` / `.txt` 按 UTF-8 读出原文
- `.pdf`、`.docx` 能抽出可见文字
- 空文件报错
- 无可提取文本的 PDF 提示不支持扫描件，不做 OCR
- 解析模块不访问数据库、不切片、不写文件

---

## T4 本地文件存储

**目标：** 校验格式与大小，安全保存到 `data/uploads/{space_id}/`。

**交付：** `backend/storage.py`、`tests/test_storage.py`

**验证：**

```text
pytest tests/test_storage.py
```

**通过标准：**

- 只接受 md/txt/pdf/docx
- 超过 10 MB 按过大处理
- `../` 等路径被净化，不能写到上传目录外
- 保存名为 `{uuid}_{safe_filename}`
- 不解析文件内容

---

## T5 数据库启动与建表

**目标：** 本地 Postgres 可连；启用 pgvector；建三张表；写入两个空间。

**交付：** `backend/db.py` 实现、`docker-compose.yml` 可用

**验证：**

```text
docker compose up -d
python -c "from backend.db import init_engine, init_db; init_engine(); init_db()"
```

再用 SQL 确认 `spaces` 中有 `student`、`company`，`documents` 与 `chunks` 表存在，`chunks.embedding` 为 `vector(1024)`。

**通过标准：**

- 不引入 Alembic
- 启动可重复执行（空间已存在不报错）
- 不创建用户、会话、工单表

---

## T6 Embedding 加载与编码

**目标：** 进程内加载一次 BGE-M3，输出归一化的 1024 维 dense 向量。

**交付：** `backend/embed.py`；单元测试用 mock，不下载真实模型

**验证：**

```text
pytest tests/test_embed.py
```

可选冒烟（本机已有模型权重时）：编码一句中文，断言长度为 1024、向量已归一化。

**通过标准：**

- `encode_documents` 与 `encode_query` 都走已加载模型，请求中不重新加载
- 单元测试不访问 Hugging Face、不调用 DeepSeek
- MVP 不使用 sparse / ColBERT / rerank

---

## T7 隔离向量检索

**目标：** 空间过滤写在 SQL `WHERE` 中，失败文档不参与检索。

**交付：** `backend/retrieve.py`、`tests/test_retrieve.py`

**验证：** 向测试库插入两条假向量（`student` / `company` 各一条，文档状态 `ready`），分别用三种允许空间检索。

```text
pytest tests/test_retrieve.py
```

测试须能检查实际 SQL：含 `chunks.space_id = ANY(...)` 且位于排序之前；`documents.status = 'ready'`。

**通过标准：**

- `allowed_spaces=["student"]` 永不返回 company 的正文、标题、文档 ID
- `employee` 只得到 company；`teaching` 可得两空间
- `failed` 文档的切片不出现
- 不先检索全库再在 Python 里丢弃无权限结果
- 本任务不调用 DeepSeek，不要求真实 BGE-M3

---

## T8 文档入库编排

**目标：** 上传后同步完成 保存 → 解析 → 切片 → 编码 → 写切片 → 标记 ready。

**交付：** `backend/ingest_service.py`、入库集成测试

**验证：** 上传一篇短 md 到 `student`；失败用例用空文件或损坏 pdf。

**通过标准：**

- 成功：`documents.status=ready`，`chunks.space_id` 与文档一致，切片数大于 0
- 失败：状态 `failed`，有简短 `error`，库中无该文档的可检索切片
- 对外错误不含密钥、堆栈、本机绝对路径
- 编码可用 mock，以免本任务绑定 GPU

---

## T9 DeepSeek 生成

**目标：** 只根据给定片段组织答案；不检索、不判断命中、不产出来源。

**交付：** `backend/generate.py`、`tests/test_generate.py`（mock OpenAI 客户端）

**验证：**

```text
pytest tests/test_generate.py
```

**通过标准：**

- Prompt 约束：只依据片段、依据不足则说明、不编造制度/步骤/成绩/来源
- 返回纯文本
- 单元测试不打真实 DeepSeek
- 超时或 API 错误向上抛出，由接口层映射为 502，不伪装成未命中

---

## T10 问答编排

**目标：** 角色 → 允许空间 → 检索 → 命中判断；未命中不调用 DeepSeek；来源来自召回记录。

**交付：** `backend/qa_service.py`、`tests/test_qa_service.py`

**验证：**

```text
pytest tests/test_qa_service.py
```

**通过标准：**

- 无结果或最高分低于阈值：`answer` 为固定拒答、`hit=false`、`sources=[]`，且 `generate_answer` 未被调用
- 分数等于阈值视为命中（边界单独测低于 / 等于 / 高于）
- 命中后来源最多 3 条、按文档去重；`document_id` / `title` / `space_id` 来自检索结果，不采信模型文本
- 非法角色按参数错误处理

---

## T11 HTTP 接口与错误语义

**目标：** 对外只暴露上传、提问、健康检查；问答不接受 `space_ids`。

**交付：** `backend/routes/*.py`、`backend/main.py` 启动时建库并加载模型、接口测试

**验证：** 用 TestClient 或 curl 打本地 API。

**通过标准：**

- `POST /documents`：成功 201；非法空间/格式 400；过大 413
- `POST /ask` 请求体只有 `role`、`question`；带 `space_ids` 应被拒绝或忽略且不影响允许空间
- 未命中 200 且 `hit=false`；数据库不可用或模型未加载 503；DeepSeek 失败 502
- `GET /health` 检查 API、数据库、BGE-M3 是否加载，不调用 DeepSeek
- 路由不写 SQL、切片或 Prompt

---

## T12 演示页

**目标：** 一张页面完成身份选择、上传、提问、展示答案与来源。

**交付：** 当时为 `backend/static/index.html`；现已删除，产品入口为 `frontend/` Vue 应用。

**验证：** 浏览器打开 `/`，走通上传与提问。无浏览器时用 curl 复现同一请求。

**通过标准：**

- 有身份下拉、问题框、答案区、来源列表、文件与空间选择
- 请求中 / 失败 / 成功三种状态可区分
- 页面不做权限控制；隔离仍由服务端执行

---

## T13 端到端验收

**目标：** 用样例文档证明入库、隔离、命中带来源、未命中拒答。

**交付：** 一篇虚构课程文档、一篇虚构内部制度（不得使用真实内部正文）

**验证：** 按 `docs/需求分析.md` 第 4.3 节手工走一遍。

**通过标准：**

- 学员能问到课程文档并带来源
- 学员问内部制度时，答案和来源中都没有该文档标题、片段或 ID
- 员工能问到公司样例；教学岗两空间都能问到
- 问库中没有的内容：`hit=false`，不出现编造链接
- 能从检索 SQL 看到空间条件先于向量排序

### V1：产品化（共享，两场景都要用）

| 任务 | 目标 | 交付 | 通过标准 |
| --- | --- | --- | --- |
| V1-T1 | 账号登录，无游客问答 | `auth`、`users`、登录页 | 未登录无法 `/ask`；密码不明文存 |
| V1-T2 | 服务端成员关系计算允许空间 | `space_members`；问答不再信任请求 `role` | 学员 token 带伪造空间仍检不到 `company`；教学岗两空间可检 |
| V1-T3 | 文档状态/失败原因/下线 | 管理接口或页 | `failed`/`offline` 不出现在检索 |
| V1-T4 | 同一会话追问 | `conversations` / `messages` | 对话不自动入库 |
| V1-T5 | 学员未命中建工单 | `tickets` | 仅学员；处理人默认班主任；502 不建工单 |
| V1-T6 | 内部未命中展示负责人 | `topic_owners` | 未配置说未配置，不编造联系方式 |
| V1-T7 | 一键部署 API + Postgres | Compose 文档 | 本机按 README 可起；仍为单体 |

V1 不实现沙箱、OCR、代码仓解析。检索 SQL 的空间 `WHERE` 不得回退到 Python 过滤。
