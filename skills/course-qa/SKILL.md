本包表示 **课程/内部知识库问答**（`POST /ask`），不注册任何 Agent 工具。

## 能力边界

- 服务端按角色计算可检索空间；空间过滤在 SQL `WHERE` 内完成。
- 命中则依据召回片段作答并附数据库来源；未命中默认拒答（学员实践参考等既有例外除外）。
- 会话可含滚动摘要（CE 压缩），摘要不进向量库。

## 禁止

- 客户端传 `space_ids` / `role` 扩大可见范围。
- 模型编造来源或把对话自动写入知识库。
- 在本路径调用进阶资料工具或任意 Shell / 未登记出网。
